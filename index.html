Liquid Glass

Open-source canvas glass. Filleted slab, inward rim refraction, shared blur. Center stays readable.

GitHub Source npm

Locked spec · rim 32 · strength 20 · chroma 0.7 · spec 0.28 · fill 0.1 · blur 2.5

Drag the pill over the type. No sliders. This is the release look.

Install

npm install github:XposeMarket/liquid-glass

Use

import { mountLiquidGlass, DEFAULT_SPEC } from "@xposemarket/liquid-glass";

mountLiquidGlass(document.querySelector("#stage"), {
  spec: DEFAULT_SPEC,
  drawScene(ctx, w, h) {
    ctx.fillStyle = "#1a1e26";
    ctx.fillRect(0, 0, w, h);
    ctx.fillStyle = "#f0f4f8";
    ctx.font = "600 42px -apple-system, sans-serif";
    ctx.fillText("drag the glass over this line", w * 0.07, h * 0.3);
  }
});

What it is

// 1 sample backdrop
// 2 shared box blur
// 3 SDF rounded-rect fillet
// 4 warp only at the rim  (|d| keeps the core identity)
// 5 inward refraction on both long edges
// 6 RGB split only at grazing angles
// 7 dark slab + faint white top/bottom hairline
